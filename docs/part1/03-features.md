# Own features

Smart reminders is committed for Part 2 (Must); Booking Clashing Reminders is commited for Part 2 (Must); the points leaderboard is a stretch goal (Nice).
## F-01 Smart reminders (Must)

- **Problem:** Students forget booked events and forget to check in, so clubs see no-shows and students miss points.
- **What it does:** Notifies booked students 1 day and 1 hour before an event, and when the club opens attendance; each type can be switched off.
- **Value:** Fewer no-shows for clubs, fewer missed points for students.
- **Scope:** In: the three reminders with on/off switches. Out: custom times, email or SMS, calendar export.

## F-02 Clashed Bookings Check (Must)

- **Problem:** Students might try to register for events that is happening with another event with the same timing, taking up extra booking slots with no goal of attending the event. 
- **What it does:** Notifies student regarding the clash, and student is not allowed to register for the second event that is clashing with the event that has previously been registered for.
- **Value:** Fewer no-shows for clubs, more slots availability, quality of life reminder for students. 
- **Scope:** In: Checking the student's existing registration records for events with the exact same time. Displaying a notification regarding the schedule clash and actively blocking the student from booking the conflicting event. Out: Providing clash-aware recommendations for alternative events or schedules.

## F-03 Points leaderboard (Nice)

- **Problem:** Points are private, so little motivates students to keep joining activities beyond their degree.
- **What it does:** The Points tab shows this semester's top 10 and the student's own rank.
- **Value:** Friendly motivation and recognition.
- **Cheating safeguard:** Only credited points count, so unvalidated check-ins cannot raise a rank and invalidation lowers it. R3 is not weakened.
- **Scope:** In: top 10, own rank, semester reset, opt-out from display. Out: club rankings, badges, rewards.

**Considered, not chosen:** clash-aware recommendations. Booking already blocks overlaps, and relevance ranking needs attendance history we will lack early on.

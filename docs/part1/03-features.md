# Own features

Smart reminders (Must) and clash detection (Must) are committed; leaderboard is Nice.
## F-01 Smart reminders (Must)

- **Problem:** Students forget booked events and miss check in, Clubs see no-shows.
- **What it does:** Notifies 1 day before, 1 hour before, and when attendance opens. Each type can be switched off.
- **Value:** Fewer no-shows, fewer missed points.
- **Scope:** In: three reminders with on/off switches. Out: custom times, email/SMS, calendar export.

## F-02 Clashed Bookings Check (Must)

- **Problem:** Students book overlapping events, wasting booking slots.
- **What it does:** Blocks booking if exact time overlap exists and names the clash.
- **Value:** Fewer no-shows, more slots availability, quality of life reminder.
- **Scope:** In – exact-time check + block + message. Out – alternative recommendations.

## F-03 Points leaderboard (Nice)

- **Problem:** Points are private;little motivates students to participate.
- **What it does:** Shows semester top 10 + own rank (credited points only). Opt-out available.
- **Value:** Friendly motivation and recognition.
- **Cheating safeguard:** Only credited points count, so unvalidated check-ins cannot raise a rank and invalidation lowers it. R3 is not weakened.
- **Scope:** In – top 10, rank, opt-out, semester reset. Out – badges, rewards, club rankings.  Only credited points count.
